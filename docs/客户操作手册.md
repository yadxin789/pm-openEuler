# PM 产品研发管理系统 · 客户操作手册

> 适用对象：系统管理员与业务用户
> 适用版本：Laravel 12 版 PM 系统（含 AI 智能助手）

---

## 一、登录系统

1. 打开浏览器，访问系统地址（HTTPS，如 `https://192.168.2.20`）。
2. 输入 **用户名** 与 **密码**，点击登录。
3. 登录成功后进入「首页」仪表盘。

> 忘记密码：联系系统管理员在「系统管理 → 用户管理」中重置。

---

## 二、常用功能

### 2.1 项目管理
- **创建项目**：进入「项目管理」，填写项目名称、代码、产品名称/型号、版本、起止周期、交付物等。
- **查看项目**：列表可查看进度与状态；点入项目详情可见其下的全部任务。
- **状态流转**：项目状态含 未开始 / 进行中 / 已完成 / 已逾期 / 已暂停。

### 2.2 任务协同
- **分配任务**：指定执行人、审核人、所属部门与起止日期。
- **任务状态**：待开始 / 进行中 / 待审核 / 已完成 / 已逾期 / 已驳回。
- **交付文件**：在任务中上传文件，支持版本管理；文件状态含 待审核 / 已通过 / 已驳回。

### 2.3 知识库
- 按分类维护制度、流程、规范文档；支持标题与正文检索。
- 文档用于规范口径，也是 AI 生成文档的参考资料来源。

### 2.4 其他
- **待办事项**：记录并跟踪待办，支持标记完成。
- **通知 / 消息**：接收系统通知与站内消息、私人消息。
- **协同文档 / 语音**：在线协作与会议语音。
- **企业微信**：若已启用，可绑定企业微信实现登录与消息互通。

## 三、AI 智能助手（重点）

### 3.1 首次开通（一次性）

侧边栏点击 **「AI 智能助手」** → 进入 **开通引导**，按三步完成：

1. **选择提供商**：DeepSeek（推荐，性价比最高）/ 通义千问 / 豆包 / 腾讯混元，任选一家。
2. **获取 API Key**：点击对应链接前往厂商平台注册并创建 API Key。
3. **粘贴并测试**：把 API Key 粘贴到输入框，保存启用；可点击「测试连接」验证。

> 也可在 **「AI 设置」**（仅管理员）中配置：提供商、API Key、Base URL、模型、温度、最大 Token、启用开关。

### 3.2 智能问答

进入 **「AI 智能助手」→ AI 聊天**，输入问题即可，例如：
- 「当前有哪些进行中的项目？」
- 「帮我查一下逾期任务」
- 「XX 项目的任务完成情况怎么样？」

AI 会调用系统工具读取 **项目 / 任务 / 用户 / 部门 / 知识库 / 文件 / 待办** 的真实数据作答，**不会编造数据**。

### 3.3 自然语言生成文档（重点功能）

进入 **「AI 智能助手」→ 文档生成**：

1. **左侧**选择文档类型模板：项目立项报告 / 工作周报 / 会议纪要 / 需求规格说明书 / 项目验收报告。
2. **右侧**用自然语言描述数据、参数和内容要求。
3. 点击 **生成文档**，AI 会自动读取 **模板文件、范例文件、知识库、支援文件**，并结合 PM 真实数据生成完整文档。
4. 在下方面板复制或编辑生成结果。

**示例描述**：
> 「为我生成一份 GUI-01 项目的立项报告，产品型号 GUI-01，周期 2026-09-28 至 2026-11-06，主要交付物包括结构设计、软件开发、样品试制。」

### 3.4 AI 数据 API（供集成/外部系统调用）

面向外部 AI 或第三方系统调取 PM 数据（项目、任务、用户、知识库等）的 REST 接口：

```
地址前缀：/api/ai
认证方式：请求头 X-AI-Key 或查询参数 api_key
密钥：.env 中的 AI_API_KEY（由部署方提供）
```

常用端点：`/api/ai/meta`（能力清单）、`/api/ai/overview`（概览）、`/api/ai/projects`、`/api/ai/tasks` 等。

> 详细端点清单见《部署说明》附录。

## 四、常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 点 AI 助手提示「AI 尚未配置」 | 进入开通引导，配置 API Key 并启用 |
| AI 回复「服务异常」 | 检查 API Key 是否有效、账户余额是否充足、服务器网络是否可访问厂商接口 |
| 文档生成结果与预期不符 | 描述更明确（数据、参数、交付物、周期）；确保知识库中有相关规范 |
| AI 是否保存我的对话 | 不存储对话；文档生成结果仅保留在当前会话 |
| 忘记密码 | 联系系统管理员重置 |

## 五、安全与使用建议

- API Key 属敏感信息，仅管理员可配置；请勿在公开渠道泄露。
- 涉及公司敏感数据时，请遵守内部信息安全规范。
- 建议定期备份数据库（见《部署说明》）。
