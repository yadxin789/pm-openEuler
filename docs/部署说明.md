# PM 产品研发管理系统 · 部署说明

> 适用对象：运维 / 部署人员
> 生产环境：openEuler（Linux），`/var/www/pm`，Apache httpd + PHP-FPM

---

## 一、运行架构

```
客户端浏览器
   │  HTTPS (192.168.2.20)
   ▼
Apache httpd  (/etc/httpd/conf.d/pm.conf, pm-ssl.conf)
   │  proxy_fcgi
   ▼
PHP-FPM  (用户 pmadmin, 服务 php-fpm.service)
   │
   ▼
Laravel 12 应用  /var/www/pm
   │
   ├── MySQL 8.4  (数据库 pm_db)
   ├── Redis/Cache (可选, 按 .env)
   └── Git 仓库  ssh://root@192.168.2.20/srv/git/pm.git
```

| 组件 | 说明 |
|---|---|
| Web 服务器 | Apache httpd（`pm.conf` 纯 HTTP，`pm-ssl.conf` HTTPS） |
| PHP | 8.3.33（CLI 与 PHP-FPM） |
| PHP-FPM 运行用户 | `pmadmin` |
| 数据库 | MySQL 8.4，库名 `pm_db` |
| 应用目录 | `/var/www/pm` |
| Git 远程 | `ssh://root@192.168.2.20/srv/git/pm.git`（分支 `master`） |
| Composer | `/usr/local/bin/composer`（符号链接 `/usr/bin/composer`，已加入 PATH） |

## 二、首次部署

### 2.1 拉取代码

```bash
# 服务器上（一次性）
git clone ssh://root@192.168.2.20/srv/git/pm.git /var/www/pm
cd /var/www/pm
```

### 2.2 安装依赖与配置

```bash
cd /var/www/pm
composer install --no-dev --no-interaction     # 生产依赖（含 laravel/ai）
cp .env.example .env                            # 若没有则从部署方获取
php artisan key:generate
```

### 2.3 数据库

```bash
php artisan migrate --force
php artisan db:seed --class=AiSeeder --force    # 初始化 AI 配置/文档模板/Skill
```

> 首次也可执行 `php artisan db:seed --force`（含全部种子，若业务数据已由部署方导入则跳过）。

### 2.4 目录权限与缓存

```bash
chown -R pmadmin:pmadmin /var/www/pm
php artisan optimize:clear
# 如需生产优化：
php artisan config:cache && php artisan route:cache && php artisan view:cache
```

### 2.5 Web 服务器

- 站点配置：`/etc/httpd/conf.d/pm.conf`（HTTP）、`/etc/httpd/conf.d/pm-ssl.conf`（HTTPS，ServerName 192.168.2.20）。
- 站点根指向 `/var/www/pm/public`，通过 `mod_proxy_fcgi` 转发到 PHP-FPM（用户 pmadmin）。
- 重启生效：`systemctl reload httpd php-fpm`。

## 三、日常更新流程

### 3.1 仅代码 / 视图变更（日常）

```bash
# 本地（Windows）
Set-Location "E:\my-pm\pm-server-openEuler"
git add -A && git commit -m "改动说明" && git push

# 服务器一键同步
cd /var/www/pm && ./deploy-views.sh
```

`deploy-views.sh` 完成：`git pull --ff-only` + 修正归属（pmadmin）+ 清/重建视图缓存。
参数：`./deploy-views.sh [分支] [REOWN] [CACHE]`（默认 master、reown=1、cache=1）。

### 3.2 涉及 composer 依赖 / 数据库迁移时

`deploy-views.sh` **不执行** composer install 与 migrate，需补充：

```bash
cd /var/www/pm
git pull origin master
composer install --no-dev --no-interaction    # 新增依赖时必做
php artisan migrate --force                   # 新增迁移时必做
php artisan db:seed --class=AiSeeder --force  # 首次或需补模板/Skill 时
chown -R pmadmin:pmadmin vendor storage bootstrap/cache
php artisan optimize:clear
```

> 若服务器 `git pull` 报「本地修改将被覆盖」，请先 `git status` 确认服务器本地改动，必要时 `git stash` 暂存后在 pull 后恢复，勿直接丢弃业务代码。

## 四、Composer 说明

- 安装位置：`/usr/local/bin/composer`（v2.10.3）。
- 已做 PATH 安装：符号链接 `/usr/bin/composer → /usr/local/bin/composer`，并在 `/etc/profile.d/composer.sh` 将 `/usr/local/bin` 加入 PATH，保证登录/非登录 shell、cron、sudo 环境均可直接使用 `composer`。
- 生产安装一律使用 `composer install --no-dev --no-interaction`。

## 五、.env 关键配置

```dotenv
APP_URL=http://localhost            # 对外使用按实际域名/IP 调整
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_DATABASE=pm_db
DB_USERNAME=root
DB_PASSWORD=***                     # 生产请使用强密码

# ---- AI 智能助手 ----
AI_ENABLED=true
DEEPSEEK_API_KEY=                   # DeepSeek 密钥（可在后台 AI 设置界面配置）
DEEPSEEK_URL=https://api.deepseek.com/v1
OPENAI_COMPATIBLE_API_KEY=          # 通义/豆包/混元 密钥（OpenAI 兼容）
OPENAI_COMPATIBLE_URL=
OPENAI_COMPATIBLE_MODEL=qwen-plus
AI_API_KEY=                         # 外部调用 /api/ai/* 的访问密钥（自行设置强随机串）
```

> 推荐在后台「AI 设置」界面配置提供商与 Key（持久化到 `ai_settings` 表），`.env` 仅为兜底默认值。

## 六、AI 数据 API 附录

认证：请求头 `X-AI-Key` 或参数 `api_key`，值为 `.env` 的 `AI_API_KEY`。

| 端点 | 说明 |
|---|---|
| `GET /api/ai/meta` | 能力清单 / 端点列表 |
| `GET /api/ai/overview` | 项目/任务/用户/部门统计 |
| `GET /api/ai/projects` | 项目列表（`status,keyword,limit`） |
| `GET /api/ai/projects/{id}` | 项目详情（含任务） |
| `GET /api/ai/tasks` | 任务列表（`status,keyword,executor,limit`） |
| `GET /api/ai/users` | 用户列表（`keyword,limit`） |
| `GET /api/ai/departments` | 部门列表 |
| `GET /api/ai/knowledge` | 知识库（`keyword,limit`） |
| `GET /api/ai/files` | 文件列表（`status,keyword,limit`） |
| `GET /api/ai/todos` | 待办事项（`completed,limit`） |
| `GET /api/ai/templates` | AI 文档模板列表 |

示例：

```bash
curl -H "X-AI-Key: <AI_API_KEY>" https://192.168.2.20/api/ai/overview
curl "https://192.168.2.20/api/ai/projects?api_key=<AI_API_KEY>&keyword=GUI"
```

## 七、备份与恢复

- **数据库**：
  ```bash
  mysqldump -uroot -p pm_db > /backup/pm_$(date +%F).sql
  ```
- **应用**：代码在 Git 仓库（可随时重新拉取）；`storage/app` 中的上传文件与 `ai_docs` 模板、`.env` 需单独备份。
- **恢复**：导入 SQL → `php artisan migrate --force` → 确认 `.env` 与权限。

## 八、故障排查

| 现象 | 处理 |
|---|---|
| 页面 500 | 查看 `storage/logs/laravel.log`；检查 `storage` 与 `bootstrap/cache` 归属是否为 pmadmin |
| 502/504 | 检查 `php-fpm` 与 `httpd` 服务状态，`systemctl status php-fpm httpd` |
| 路由 404 | 执行 `php artisan optimize:clear`（清路由缓存） |
| AI 报错 | 检查 API Key 与账户余额、服务器外网访问厂商接口；查看 laravel.log |
| composer 找不到 | 已安装于 `/usr/local/bin` 并做符号链接，直接 `composer` 即可 |
